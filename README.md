# UrsaBot

An old hobby project: a Discord bot written in JavaScript (Node.js).

It has music playback, voice channel support and a simple command system. I built it for fun and to learn, and it's no longer maintained. I'm keeping it here for reference.

## Structure

- `commands/` – bot commands
- `Interaction/` – interaction handling
- `Music/` – music playback
- `Voice/` – voice channel handling
- `utility/` – helper functions
- `Bot.js`, `BaseClient.js`, `GuildManager.js` – core bot logic
- `index.js` – entry point

## Run

    npm install
    node index.js

You'll need to provide your own Discord bot token.

## Status

Archived. Expect outdated dependencies, rough edges and no guarantees.
